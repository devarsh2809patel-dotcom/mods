# Promptmaster

A Claude Code mod that rewrites your rough draft into a clear prompt before you send it. It never answers the draft and never sends anything. Click Promptmaster in the band above the input, or run /promptmaster <draft>. Review the result, then press Use it or Edit to put it in the input box. Two modes: pipeline (long or big tasks) and iterative (short follow-ups), picked automatically or set with the Mode button. Edit the templates in the plugin settings.
